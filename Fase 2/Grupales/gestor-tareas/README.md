# Gestor de Tareas – Alloy

Aplicación web interna para gestión de tareas, horas trabajadas, perfiles de usuario y solicitudes de permisos/vacaciones.

Construida con **React + Vite**, **TailwindCSS** y **Supabase** (Auth, DB y Storage).

---

## Requisitos previos

Antes de iniciar el proyecto, asegúrate de tener instalado en tu PC:

- **Node.js** (recomendado LTS)
- **npm** (se instala junto con Node)
- **Visual Studio Code** (o editor similar)

Verifica instalación:
```bash
node -v
npm -v

## istalar graficos
npm install recharts lucide-react

## iniciar la app
npm run dev

## instalar reportes
npm install jspdf jspdf-autotable

## instalar confeti cumpleaños
npm install canvas-confetti
